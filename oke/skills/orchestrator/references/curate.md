# Orchestrator: wiki curation

When `job archive` prints a `curate:` line, or the user asks to clean up a wiki, give that wiki's PM `kind: curate` (it needs a job: `job new <name> --pm <pm> --research`, no path, no PM question needed, no interview needed: run `$OKE interview <job> --goal 1 --constraints 1 --criteria 1`, then phase `working`). For the shared wiki do the same yourself with `--shared`.
