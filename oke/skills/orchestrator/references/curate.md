# Orchestrator: wiki curation

When `job archive` prints a `curate:` line, or the user asks to clean up a wiki, give that repository's PM `kind: curate` (it needs a job: `job new <name> --repo <path> --research`, no interview needed: run `$OKE interview <job> --goal 1 --constraints 1 --criteria 1`, then phase `working`). For the shared wiki do the same yourself with `--shared`.
