# OKe 조각 1 (뼈대) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사용자가 orchestrator 세션 하나에 작업 1개를 지시하면 PM, worker, reviewer 가 herdr pane 에서 계획, 구현, 리뷰, merge 까지 끝내는 Claude Code 플러그인 `oke` 를 만든다.

**Architecture:** 판단은 역할 skill 4개가 하고, 정해진 절차 (하위 띄우기, 보고 대기, 상태 대조, 상태 파일 쓰기) 는 `oke.py` 한 파일이 고정한다. agent 사이의 통신은 `~/.oke/` 아래 파일 (배정, 보고, 현황판) 이고, 상위는 백그라운드 `oke wait` 가 끝날 때 깨어난다.

**Tech Stack:** Python 3.6 호환 표준 라이브러리 (`unittest`, `json`, `subprocess`, `argparse`), herdr CLI, Claude Code 플러그인 (skills, commands, hooks).

**Spec:** `docs/superpowers/specs/2026-11-13-oke-slice1-design.md`

## Global Constraints

- Python 3.6 문법만: f-string 은 가능, walrus (`:=`), `match`, `dict | dict`, `subprocess.run(capture_output=)`, `text=` 인자, 타입 힌트의 `list[str]` 는 금지. 표준 라이브러리만.
- 외부 명령은 항상 argv 목록으로 실행한다. 셸 문자열을 만들지 않는다.
- herdr 버전을 숫자로 비교하지 않는다. 필요한 하위 명령의 `--help` 성공 여부만 본다.
- 실행 폴더는 `~/.oke/`. 테스트는 환경 변수 `OKE_HOME` 으로 바꾼다. herdr 실행 파일은 `OKE_HERDR` (공백으로 나눈 argv, 기본 `herdr`) 로 바꾼다.
- 파일마다 쓰는 주체는 1명. JSON 은 임시 파일에 쓰고 `os.replace` 로 교체한다.
- 완료 판정은 보고의 `seq` 로 한다. 파일 수정 시각과 경과 시간을 판정에 쓰지 않는다. `oke wait` 에 시간 제한을 두지 않는다.
- agent 이름은 `[a-z][a-z0-9_-]{0,31}`. PM `pm-<저장소>`, worker `<job>-w1`, reviewer `<job>-rv`. job slug 는 24자.
- 보고 `type`: `done | question | blocked | failed | waiting`. `phase`: `intake | planning | awaiting_approval | working | reviewing | awaiting_merge | done | failed`.
- 자동으로 지우지 않는 것: worktree, branch, `jobs/` 의 내용 (보관은 `archive/` 로 이동).
- commit 메시지 끝: `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.

## Review Focus

1. 보고 파일을 쓰는 도중에 읽음 (머리말이 반만 있음): agent 가 `working` 인 동안은 `bad_report` 로 판정하지 않는다. Task 5.
2. herdr 서버가 죽었거나 JSON 이 아닌 출력을 냄: `gone` 으로 오인하지 않고 종료 코드 2 와 오류 문구로 끝낸다 (`gone` 은 "보관할까" 질문으로 이어지므로 오인하면 위험). Task 3, 5.
3. 저장소 경로에 공백이나 한글이 있음, Windows 에서 `C:/x` 와 `/c/x` 와 `c:\X` 가 섞임: 같은 저장소 키가 나온다. Task 2.
4. 저장소 이름에 대문자, 점, 밑줄이 있거나 길다 (`My.Repo_v2`), 이미 같은 이름의 agent 가 살아 있음: 이름을 규칙에 맞게 바꾸고, 겹치면 덮지 않고 실패한다. Task 4.
5. 첫 실행 (`~/.oke` 없음, `state.json` 없음, `config.json` 없음): 만들고 기본값으로 진행한다. Task 2.

**Interfaces:**
- Produces:
  - `oke_home() -> str`: `OKE_HOME` 또는 `~/.oke` 의 절대 경로. 없으면 만든다.
  - `load_config() -> dict`: 기본값 `{"autonomy": "balanced", "wiki_path": "<home>/wiki", "models": {"pm": "opus", "worker": "sonnet", "reviewer": "sonnet"}}` 위에 `config.json` 을 덮는다. `wiki_path` 의 `~` 를 편다.
  - `read_header(path) -> dict | None`: 첫 `---` 줄 전까지의 `key: value` 줄. 파일이 없거나 `---` 가 없으면 `None`. 값은 문자열, `seq` 만 `int`.
  - `write_json_atomic(path, obj) -> None`
  - `load_state() -> dict`: 없으면 `{"orchestrator": {}, "repos": {}, "jobs": {}}`. 못 읽으면 `state.json.bad` 로 바꾸고 같은 빈 값에 `"_recovered": True` 를 넣어 돌려준다.
  - `save_state(state) -> None`: `_recovered` 를 빼고 쓴다.
  - `repo_key(path) -> str`: `git rev-parse --git-common-dir` (cwd=`path`) 결과를 `path` 기준 절대 경로로 만든 뒤 정규화. 정규화: `/c/x` 꼴을 `c:/x` 로, 역슬래시를 `/` 로, Windows 에서는 소문자로, 끝의 `/` 제거. git 저장소가 아니면 `ValueError`.
  - `slug(text, limit=24) -> str`: 소문자, `[a-z0-9-]` 밖은 `-`, 연속 `-` 는 1개, 앞이 글자가 아니면 `x` 를 붙임, `limit` 로 자름.
  - CLI `oke.py job new <slug> --repo <path>`: `jobs/<slug>/` 를 만들고 `state.json` 에 `phase: intake` 로 넣는다. 이미 있으면 종료 코드 1.
  - CLI `oke.py job phase <slug> <phase>`: 허용된 값이 아니면 종료 코드 1.
  - CLI `oke.py job archive <slug>`: `jobs/<slug>` 를 `archive/<slug>-<YYYYMMDD-HHMMSS>` 로 옮기고 `state.json` 에서 뺀다.

### Task 4: `oke spawn`

**Files:**
- Modify: `oke/bin/oke.py`, `oke/bin/test_oke.py`

**Interfaces:**
- Consumes: `read_header`, `load_config`, `load_state`, `save_state`, `write_json_atomic`, `repo_key`, `herdr`, `herdr_text`, `HerdrError`. `docs/probe-results.md` 의 결정 1, 2, 4.
- Produces:
  - CLI `oke.py spawn <assignment.md> (--pane <id> | --split-from <id>) [--resume <session>]`. 표준 출력 한 줄 JSON `{"agent": ..., "pane": ..., "session": ...}`. 실패하면 종료 코드 1 과 stderr 한 줄 이유. 모르는 창이면 stderr 에 화면 글도 싣는다.
  - `launch_args(role, config, home, plugin_dir, resume=None) -> list`: `--` 뒤에 붙일 claude 인자.
  - `TRUST_MARKER = "trust this folder"` (화면 글을 소문자로 바꿔 포함 여부를 봄).
  - 기록: `role == "pm"` 이면 `state.json` 의 `repos[<repo_key(cwd)>]["pm"]` 에, 아니면 `repos/<pm 폴더>/children.json` 의 `[agent]` 에 `{"agent", "pane", "session", "seq", "job", "role"}` 를 쓴다. PM 폴더는 `<home>/repos/<slug(저장소 폴더 이름)>/pm`.

절차 (이 순서가 테스트의 기대값):
1. 머리말에서 `agent`, `role`, `cwd`, `job`, `seq` 를 읽는다. 하나라도 없으면 실패.

한 번의 확인 (`check_once(agent, report, seq) -> str | None`, `None` 은 "계속"):
1. `h = read_header(report)`. `h` 가 있고 `h["seq"] == seq` 이고 `h["type"]` 이 `done/question/blocked/failed` 중 하나면 `report <type>`.
2. `herdr agent get <agent>`. `agent_not_found` (또는 pane 없음) 이면 `gone`.
3. `agent_status == "blocked"` 면 `blocked` + 화면 글.
4. `agent_status` 가 `working` 또는 `unknown` 이면 `None`.
5. 여기부터 `idle` / `done`: `h` 가 있고 `seq` 가 같고 `type == "waiting"` 이면 `None`.
6. 파일이 있고 (`h is None` 이거나 `type` 이 허용값이 아님) 이면 `bad_report <이유>`. `seq` 가 작거나 파일이 없으면 `idle_no_report`.

5, 6 의 판정은 `idle` 이 연속 3번 확인될 때만 낸다 (키를 보낸 직후의 낡은 상태, 쓰는 도중의 파일을 거름). 그 전에는 `None`.
